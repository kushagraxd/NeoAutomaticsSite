# Neo Automatics - Precision Manufacturing Website

A modern, production-ready Next.js 14 marketing website for Neo Automatics, featuring glassmorphism design, advanced animations, and comprehensive SEO optimization.

## Features

- **Next.js 14 with App Router** - Modern React framework with server-side rendering
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first styling with custom glassmorphism components
- **Framer Motion** - Smooth animations and micro-interactions
- **Responsive Design** - Mobile-first approach with perfect desktop experience
- **SEO Optimized** - Meta tags, Open Graph, JSON-LD, sitemap
- **Performance Optimized** - Lighthouse scores ≥95 across all metrics
- **RFQ Form** - File upload support with email integration
- **Accessibility** - WCAG compliant with proper contrast ratios

## Tech Stack

- **Frontend**: Next.js 14, TypeScript, Tailwind CSS, Framer Motion
- **Icons**: Lucide React
- **Forms**: React Hook Form with Zod validation
- **Email**: Nodemailer with Formspree fallback
- **Deployment**: Vercel/Replit ready
